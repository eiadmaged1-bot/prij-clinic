# Theme Tokens

Core tokens are defined in `css/handoff.css`.

```css
--bg
--surface
--surface-soft
--text
--muted
--border
--brand
--brand-strong
--accent
--warning
--danger
--success
--radius
--shadow
```

Preferred visual balance:
- Light clinical surfaces.
- Strong but restrained navigation.
- Clear alert colors for blocked, draft-only, and review-required states.
- No single-hue wash across the whole interface.
