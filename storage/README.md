# Local Private Storage

This folder is for local development notes only. Real guideline PDFs, licensed files, extracted text, imports, uploads, and temporary files must stay ignored and must not be committed.

Guideline uploads are stored locally under `storage/guidelines/private/` by the API. Use demo files only during development.

Future production work should add encrypted object storage, backup policy, retention rules, and restore tests before real clinical or licensed files are used.
