# Clinic Portal UI Plan

Date: 2026-06-28

The `medicolize-portal` theme is an original Prij Clinic owner portal inspired by common clinic-portal layout patterns. It does not copy competitor branding, logo, assets, text, icons, or proprietary UI.

## Implemented In V0.1

- Deep purple left sidebar.
- Top bar with patient search.
- Compact module navigation with small badges.
- Owner dashboard cards for patients, calendar, queue, lab orders, finance, and owner controls.
- Patient-centered workspace tabs.
- Hidden owner/admin navigation for non-admin users.

## Planned

- Real patient search behavior across patient files and appointments.
- Owner/receptionist/doctor dashboard variants.
- Patient timeline with safe filtering.
- File and gallery areas only after secure PHI storage is implemented.
- Inventory, messaging, analytics, and support as future modules.

## Safety

- No real patient data.
- No diagnostic AI.
- No real payment gateway.
- No PHI uploads.
- Admin tools remain backend protected and audited.
