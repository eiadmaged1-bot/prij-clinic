# Mobile First Rules

Primary QA order is mobile, tablet, laptop, then desktop. Target widths: 320, 375, 390, 430, 768, 834, 1024, 1366, 1440, and 1920 px.

Normal UI must have no horizontal scroll, overflowing Arabic labels, unlabeled inputs, raw URLs, dead buttons, developer overlays, broken placeholder bars, giant all-record dropdowns, or fake/demo/test/QA/runtime records.

The top bar must keep Dr Maged Attia Clinics, عربي | EN, and Logout visible. Navigation drawers are secondary.
