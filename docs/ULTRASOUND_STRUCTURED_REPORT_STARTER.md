# Ultrasound Structured Report Starter

The OB ultrasound report starter records scan date/time, scan type, indication, pregnancy episode, fetus link, gestational age, fetal presentation, placenta, amniotic fluid note, fetal heart note/rate, BPD, HC, AC, FL, EFW, Doppler note, and doctor-written impression.

The report can be printed from the browser. There is no DICOM/PACS, diagnostic image AI, automatic FGR diagnosis, automatic anomaly diagnosis, or percentile interpretation unless a future deterministic reviewed calculation is explicitly added and labeled as calculation only.

Doctor final interpretation is required.
