# Care Assist Workflow QA

Care Assist runs inside the visit using existing patient/history/encounter/prescription/investigation context.

It can show missing-field and safety-review findings for documentation, history, medication safety, investigations, and follow-up. Findings can be accepted, dismissed, snoozed, or resolved. High and critical review dismissals require a reason.

Care Assist does not finalize diagnosis, prescribe medication, sign records, or silently write final clinical documentation.
