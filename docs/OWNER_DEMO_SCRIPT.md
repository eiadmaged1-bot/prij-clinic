# Owner Demo Script

## Goal

Show owner/admin controls while keeping safety and access boundaries clear.

## Script

1. Sign in as `eyad` / `eyad` in the local demo.
2. Open Admin.
3. Review staff users, roles, service catalog, safety settings, and audit viewer.
4. Edit a demo service price or deactivate/reactivate a service.
5. Open Appearance.
6. Switch between Original Premium, Clinic Portal, Incision Portal, Minimal Clean, and Compact Operations.
7. Use Comfort, Large, and Compact display controls from the top bar.
8. Return to Dashboard and Doctor Mode to show the visual changes.

## Safety Notes

- Admin changes are for local demo review only.
- Appearance settings are protected from non-admin staff.
- Audit logs cannot be deleted from the normal app.
- Signed clinical records cannot be silently hard-deleted.
