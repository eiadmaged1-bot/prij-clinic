# UI Density And Empty States

Density lock rules:
- One number uses `.mini-metric-card` inside `.compact-metric-grid`.
- Two or three facts use `.compact-panel`.
- Many rows use `.dense-card-list` or tables.
- No data uses `.smart-empty-state.compact`.
- Workflow explanations use `.collapsible-help-panel` and default collapsed.

Doctor Comfort Mode remains readable with larger controls, but it should not create huge empty panels or excessive whitespace.
