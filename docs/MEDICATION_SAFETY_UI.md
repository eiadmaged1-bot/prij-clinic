# Medication Safety UI

Normal medication cards show medication name, class/family, pregnancy status, lactation status, reference status, and action.

Source name, source year, source link, confidence, last checked, source last updated, reviewed by, and reviewed at belong in advanced/admin details, not the normal card list.

Bulk wording must be "Approve all for reference display" and the resulting status is "Approved for reference list". This never means clinically safe in pregnancy or lactation. Keep "Clinical safety: Doctor review required."
