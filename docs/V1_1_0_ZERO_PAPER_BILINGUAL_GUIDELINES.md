# v1.1.0 Zero-Paper Bilingual Guidelines

v1.1.0 improves the zero-paper clinic workflow and adds the bilingual UI foundation.

- The `EN / عربي` language switcher is in the top-right shared shell.
- Arabic mode applies RTL layout.
- `كشف`, `إعادة`, `استشارة`, and `مستعجل` stay Arabic in all languages.
- `مستعجل` means urgent examination / `كشف مستعجل`.
- The receptionist and doctor workflows now carry required visit type context.
- Guideline Library stores, browses, and searches only indexed local or allowed sources.
- No paywall bypass, copyrighted guideline PDFs/text, or external AI is enabled by default.
- Evidence answers require citations and doctor review.
- Real patient data remains blocked until signoff.
