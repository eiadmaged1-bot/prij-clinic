# Patient Documents Results Timeline

Patient documents remain patient-specific and metadata-first. Existing upload protection remains intact: image metadata stripping, unsafe file type rejection, confidentiality checks, and no raw storage paths in normal UI.

Document/result entries may link to a visit, order, report, result, consent, prescription, uploaded user, category, status, and created date where the current model supports it.

No real PHI files are included in tests or seeds. Do not commit uploads, generated reports, PDFs, Excel files, raw imports, screenshots, or storage folders.
