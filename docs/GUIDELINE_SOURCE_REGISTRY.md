# Guideline Source Registry

Seeded registry sources:

- WHO
- NICE
- RCOG
- ACOG
- FIGO
- ESHRE
- ASRM
- SMFM
- CDC
- SOGC
- WSES
- SAGES

The registry is metadata only. Seeded sources are not imported documents.

Source types:
- `OPEN_PUBLIC`: generally public/open, still import only direct safe documents.
- `PUBLIC_RESTRICTED`: public page but reuse/license needs review.
- `LICENSED_UPLOAD`: private owner-uploaded licensed files.
- `LOGIN_REQUIRED`: do not import.
- `LINK_ONLY`: keep link metadata only.
- `DO_NOT_IMPORT`: blocked from import.
