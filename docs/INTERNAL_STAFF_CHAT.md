# Internal Staff Chat

Internal staff chat supports:

- Doctor to Doctor
- Doctor to Receptionist
- Receptionist to Doctor
- Owner/Admin to staff
- Per-recipient message receipts with `seenAt`
- Unread count in the shared top bar

Staff chat is not a formal clinical note. Patient-linked messages are operational context only and require patient-link chat permission.

No WhatsApp, SMS, or external chat integration is included.
