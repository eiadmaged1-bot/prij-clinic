# Guideline Library Imports

Guideline Library is search-first. Doctors see Search Guidelines, Browse Guidelines, Ask Evidence Library, and Saved/Recent. Owner/Admin can access Upload Licensed PDF, Sources Registry, Needs Review, and Private Vault when permitted.

Guideline PDFs are stored only in gitignored private storage. Do not commit PDFs to GitHub.

No paywall bypass, login-only scraping, or restricted-source scraping is allowed. Restricted or unclear copyright sources are link-only or require manual licensed upload.

`npm run guidelines:import:official` uses the official/open import path when runtime access and allowlisted sources are available.
