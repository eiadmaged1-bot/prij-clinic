# Zero-Paper Workflow

The zero-paper workflow centers reception, queue, doctor visit, patient timeline, documents, consents, and print packet actions inside the app.

Reception can create or find a patient, choose the required visit type, and add the patient to the queue. The patient file exposes quick actions for visit, prescription, investigation, payment, document placeholder, print packet, follow-up, QR, and consent placeholder.

No real patient data or committed document files are allowed.
