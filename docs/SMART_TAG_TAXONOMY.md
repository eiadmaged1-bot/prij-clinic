# Smart Tag Taxonomy

Smart Clinical Search is category-first: choose a category, tap a human-readable tag chip with counts, and results load immediately.

Categories include patient workflow, current pregnancy, OB history, pregnancy risks, gynecology complaints/diagnoses, infertility/ART, operations, oncology/screening, medical history, infection/STI, safety/allergy, medication-related, and administrative/follow-up.

Normal UI must not show snake_case/internal codes. Aliases such as CS/Cesarean/C-section, D&C/DNC/Curettage, RPL, GDM, PIH, PMB, AUB, ICSI/IVF/ART, and PID should resolve through search.
