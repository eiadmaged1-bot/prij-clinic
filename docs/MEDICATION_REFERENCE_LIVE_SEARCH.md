# Medication Reference Live Search

Medication reference changes:
- medication and official medicine searches run live with a short debounce
- Search button remains as backup
- result ordering favors exact, starts-with, contains, family, and source-verified matches
- drug family chips are buttons grouped by practical family buckets
- family selection is only a search filter and never auto-prescribes
- placeholder/catalog-only wording is shown as Catalog only or Needs source review

Official medicine status wording separates source verification from clinical safety review:
- Source verified
- Needs source review
- Clinical review required
- Conflict / duplicate
- Retired / unavailable
