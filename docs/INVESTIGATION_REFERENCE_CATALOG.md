# Investigation Reference Catalog

The investigation catalog is used for request selection and previous-investigation history.

Boundaries:
- No interpretation.
- No diagnosis automation.
- No pricing or billing/package wording.
- No automatic clinical recommendations.

v0.12.2 expands categories for laboratory, radiology, ultrasound, pathology, microbiology, cytology, hormonal tests, fertility tests, prenatal/OB tests, and gynecology-related investigations.
