# Receptionist Single Screen Workflow

Receptionist home is the daily front-desk page.

It shows:
- Waiting now
- With doctor
- Next patient
- Waiting list
- New Patient
- Returning Patient
- Scan QR / manual flow

It does not show owner analytics, finance totals, broad dashboards, tasks, documents, patient file menus, or duplicate check-in surfaces as normal receptionist clutter.
