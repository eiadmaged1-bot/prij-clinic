# Drug Market Country Badges

Badge rules:
- Egypt product: no compact country badge by default.
- KSA-only product: KSA badge.
- UAE-only product: UAE badge.
- Yemen-only product: YEM badge.
- KSA + UAE without Egypt: KSA + UAE badges.
- Egypt plus another country: compact badges hidden, expanded profile lists all countries.

Rules are stored in `DrugMarketCountry` and recomputed into `DrugMarketAvailability`.
