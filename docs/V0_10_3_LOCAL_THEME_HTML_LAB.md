# V0.10.3 Local HTML UI Theme Lab

Branch: `ui/v0.10.3-local-theme-html-lab`.

Scope: UI/design export only. No backend clinical logic, medication data, database records, API integration, external AI, RBAC changes, audit changes, or release tag.

## Purpose

The sprint expands the local HTML export from a login-only preview into a standalone clickable clinic UI prototype. The owner can open the app shell directly in a browser and inspect desktop, tablet, and mobile states without running the API or Next.js app.

The standalone lab opens directly to Dashboard, and the mobile HTML export opens directly to the mobile dashboard. Login remains present only as a visual preview section. Its `Enter UI Lab` button switches back to Dashboard and does not authenticate, call an API, create a session, or bypass the real application.

## Generated Files

```text
docs/design/prij-ui-theme-lab.html
docs/design/prij-mobile-ui-lab.html
```

Both files are generated by:

```text
scripts/export-ui-theme-html.mjs
```

The generator writes self-contained HTML with inline CSS and inline JavaScript for navigation, theme switching, mobile drawer behavior, and viewport preview controls.

Each generated file displays the banner `Static UI Lab — no real login required` and the note that this is a static design prototype where real app login/RBAC still applies in the production app.

## Mobile Behavior

The mobile export is phone-first for 390px browsing. The shared prototype also includes viewport buttons for Mobile 390px, Tablet 768px, and Desktop full. Cards stack on mobile, forms collapse to one column, patient tabs scroll horizontally, table examples become mobile card lists, and command blocks wrap safely.

## Safety Notes

The lab uses neutral placeholders only, including `Patient file`, `MRN pending`, `Official medication rows: 0`, and `Medication selection blocked until official rows exist`.

It includes no API calls, no external CDNs, no real PHI, no secrets, no fake database data, no medication dosing examples, no medication instruction rows, and no clinical decision automation. Clinical and AI areas remain draft-only until reviewed and approved by a doctor.
