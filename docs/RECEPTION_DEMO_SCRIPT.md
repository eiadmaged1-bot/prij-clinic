# Reception Demo Script

## Goal

Show front-desk patient registration, search, appointment, queue, and billing entry points without real patient data.

## Script

1. Sign in locally.
2. Open Patients.
3. Use Search patient files to find a demo patient.
4. Click New Patient File.
5. Enter fake demo details only.
6. Save and open the patient file.
7. Use patient actions for Appointment, Check In, Consent, and Invoice.
8. Open Queue to show the waiting list workflow.
9. Open Billing to show demo invoice records.

## Boundaries

- No real identifiers, phone numbers, addresses, or payment details.
- No real report files.
- No production scheduling or billing claim is made.
- Admin tools should not be visible to non-admin staff.
