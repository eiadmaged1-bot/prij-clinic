# Patient Timeline

The patient timeline is consolidated around a single patient file. It can show patient creation, appointments, queue events, encounters, prescriptions, medication safety review events, investigations, reports, documents, follow-ups, invoices/payments, gynecology visits, pregnancy records, antenatal visits, and ultrasound events where existing audit and model data support them.

Unauthorized roles must not see sensitive clinical details. Normal UI must not show raw JSON, endpoints, schema names, stack traces, Prisma wording, or developer labels.
