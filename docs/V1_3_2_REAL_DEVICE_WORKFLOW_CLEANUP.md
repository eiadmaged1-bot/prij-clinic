# v1.3.2 Real Device Workflow Cleanup

v1.3.2 is a real-device QA cleanup after v1.3.1. It focuses on Tailscale runtime access, always-visible logout, receptionist cockpit simplification, role-based navigation cleanup, removal of demo/test/training records from normal UI, patient-context clinical tools, guideline import foundations, and the Pharmacology workspace.

External AI remains disabled by default. AI output is draft-only and requires doctor approval. No autonomous diagnosis, prescribing, dosing, or treatment ranking is allowed.
