# Missing Fields Engine

The missing fields engine checks existing patient context for documentation gaps.

Current examples:
- Chief complaint.
- HPI.
- Menstrual history.
- OB history.
- G/P/A/L.
- LMP.
- Pregnancy status.
- Lactation status.
- Contraception history.
- Past surgical history.
- Medication history.
- Allergy history.
- Previous investigations.
- Follow-up plan.

Findings remain prompts only. They do not write clinical content or finalize a plan.
