# Egypt Gulf Drug Market Database

Target countries:
- EG: Egypt.
- KSA: Saudi Arabia.
- UAE: United Arab Emirates.
- QAT: Qatar.
- KWT: Kuwait.
- BHR: Bahrain.
- OMN: Oman.
- YEM: Yemen.

The database stores product groups and marketed variants: trade name, generic/scientific name, strength text, dosage form, route, package, registration number, manufacturer, marketing company, source, and review status.

Marketed strength/form/pack data is market metadata only. It is never patient directions, frequency, treatment planning, automatic dose advice, or automatic prescription text.

Egypt, Saudi Arabia, UAE, Qatar, Kuwait, Bahrain, Oman, and Yemen require official registry/API/file sources or licensed provider files. Retail metadata remains disabled by default and cannot override official registry data.
