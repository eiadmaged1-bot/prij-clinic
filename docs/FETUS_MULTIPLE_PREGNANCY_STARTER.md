# Fetus Multiple Pregnancy Starter

Fetus records can be added inside a pregnancy episode using labels such as A, B, or C. Fields include chorionicity, amnionicity, status, and fetus-specific notes.

Ultrasound reports can link to a fetus record when one exists.

This is a starter only. It does not add fetal image AI, automatic FGR diagnosis, twin surveillance algorithms, or automatic fetal risk interpretation.
