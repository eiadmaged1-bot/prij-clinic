# Daily Reports

Daily reports summarize clinic operations without adding insurance, ledger, or PHI export workflows.

Included summaries:

- Daily appointments
- Check-ins and queue
- Completed visits
- Invoices issued
- Payments collected
- Outstanding balances
- Investigations requested
- Pending results
- Follow-ups due
- Owner daily summary
- Reception daily summary
- Doctor daily summary

Reports are role-aware through existing RBAC and API authorization. Reception sees operational summaries, doctors see clinical workflow summaries, and Owner/Admin users see business summaries.
