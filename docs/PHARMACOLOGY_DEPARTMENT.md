# Pharmacology Department

The medication page is now a Pharmacology / Medication Reference workspace. It supports search by generic, brand, class, and function.

Quick filters include pain killers, antibiotics, antiemetics, antihypertensives, contraception, progesterone/fertility, diabetes, and thyroid.

Country support includes Bahrain and Oman. Libya is future/imported-only until an official source file or owner-approved URL import is available.

Prescription workflow should prefer generic names. No prices, stock, inventory, sales, cart, checkout, or pharmacy availability wording belongs in prescription workflow.
