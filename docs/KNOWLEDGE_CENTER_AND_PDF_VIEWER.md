# Knowledge Center and PDF Viewer

Authoritative same-origin PDF bytes support private no-store range responses. PDF.js renders canvas pages, selectable text, search highlights, and on-demand thumbnails. The server page count is reconciled with the actual PDF page count. If rendering fails, the UI states exactly: “PDF rendering unavailable — Text fallback mode,” with Retry PDF and Open Original.

The existing 52-document inventory was not overwritten or reimported. Uploads retain hash/audit governance. PDF signatures must match and active/embedded PDF actions are rejected. Visual opening of a stored document remains manual QA.
