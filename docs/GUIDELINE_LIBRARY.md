# Guideline Library

Guideline Library supports browsing and source management for allowed local/open sources.

Supported registry sources include ACOG, RCOG, NICE, WHO, FIGO, ESHRE, ASRM, SMFM, CDC, and other women’s health sources.

No paywall bypass is allowed. No copyrighted guideline PDFs or long guideline text are committed. Local uploads belong only in ignored storage/uploads.
