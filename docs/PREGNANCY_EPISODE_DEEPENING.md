# Pregnancy Episode Deepening

The patient workspace now exposes a Pregnancy tab for doctors, Owner, and Admin. It can create a pregnancy episode with LMP, EDD, dating method, gravida, para, living, abortions, status, and doctor notes.

Gestational context is displayed from recorded dates and clinician-entered fields. The app does not auto-diagnose preeclampsia, FGR, SGA, or any other risk condition.

Doctor interpretation is required.
