# Clinical Recommendation Boundaries

Care Assist improves completeness and safety visibility only.

It does not:
- Diagnose.
- Prescribe.
- Choose drugs.
- Generate dose, frequency, duration, or patient instructions.
- Rank treatments.
- Create a final clinical plan.
- Replace doctor review.

Medication profile wording must use:
- Reference only.
- Doctor review required.
- Legacy pregnancy category.
- Lactation profile.
- Source.
- Review required.

Medication profile wording must not use:
- Recommended drug.
- Best drug.
- Safe drug.
- Use this.
- Dose suggestion.
- Treatment ranking.
- AI doctor.
