# Guideline Upload and Review

Authorized Doctor/Owner/Admin users can upload PDF, TXT, or Markdown with title, specialty, topic, source, version, access, and license metadata. The server checks MIME plus extension, size, duplicate SHA-256, safe filename/storage, encryption configuration, extraction, indexing, RBAC, and audit.

Uploaded text is untrusted retrieved evidence. It cannot become clinical authority or update a patient record. Reviewers approve, reject, supersede, or archive through audited decisions. The stable-ID viewer provides TOC, within-document search, section navigation, source/version/status, and citations where indexed.

DOCX, persistent annotations, and complete version-replacement UI remain incomplete.
