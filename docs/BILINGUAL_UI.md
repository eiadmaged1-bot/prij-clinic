# Bilingual UI

The shared shell includes `EN / عربي` in the top-right beside account/logout.

English uses LTR. Arabic uses RTL. Preference is stored in `localStorage` as `prijClinicLanguage`.

Clinical safety labels remain translated, and AI output remains draft-only until reviewed by a doctor.

`كشف`, `إعادة`, `استشارة`, and `مستعجل` stay Arabic in both languages.
