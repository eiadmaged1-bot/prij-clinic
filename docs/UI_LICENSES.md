# UI Licenses And Inspiration Policy

Date: 2026-06-30

This sprint uses license-safe UI inspiration and locally customized implementation only.

## Approved Sources

- shadcn/ui: used as open-source/open-code component inspiration only. Components are customized locally; no paid template is copied.
- Radix UI: approved accessible primitive source if a future component needs it. Not required by the current implementation.
- Lucide: approved MIT-licensed fallback line icons through `lucide-react`.
- Iconify: approved icon framework if later needed. Individual icon-set licenses must be checked before use.
- 3dicons.co: may be used only if the CC0 license is confirmed and documented before adding assets.

## Current Sprint Assets

- The premium 3D icon system uses local lightweight SVG/CSS gradient badges and Lucide line icons.
- No remote icon URLs are loaded at runtime.
- No binary icon packs are committed.
- No paid templates, competitor screenshots, competitor logos, copied layouts, copied wording, or proprietary theme assets are used.

## Medical Product Boundaries

- UI changes do not add clinical decision logic.
- UI changes do not add real AI calls.
- UI changes do not add a real payment gateway.
- Demo records remain fake/local only.
