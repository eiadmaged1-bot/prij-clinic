# OB Workspace Rules

OB Summary is the default OB view: G/P/A/L, EDD, GA today, previous delivery summary, active pregnancy status, high-risk alerts, and focused actions.

If no OB data exists, show one compact card: "OB history not recorded yet" with Add OB history. Do not show multiple huge "Not recorded" blocks.

Chips must not create G/P/A/L counts. Previous delivery summaries must come only from saved structured previous pregnancy records. If saved G/P/A/L conflicts with previous deliveries, show a mismatch warning and block final print/export until reviewed.
