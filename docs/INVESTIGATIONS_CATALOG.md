# Investigations Catalog

The investigations request UI is organized by clinical categories instead of a flat list.

Required categories include Routine Labs, Obstetric Investigations, Gynecology Investigations, Infertility Investigations, Recurrent Abortion / RPL, Tumor Markers / Gyn Oncology, Cervix / Pap / HPV / Colposcopy, Endometrial pathology, Ovarian tumors, Imaging / Radiology, Ultrasound-related requests, and Pathology / Cytology / Histopathology.

Favorites are user-specific. High Priority / Common is system-defined. Templates only add items to a request draft; the doctor can remove or edit before saving.
