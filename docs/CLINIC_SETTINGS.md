# Clinic Settings

Clinic settings polish in v0.15.0 covers the owner/admin-facing concepts needed for MVP operations:

- Clinic name
- Phone
- Address
- Working hours
- Default appointment duration
- Default currency
- Invoice prefix/default numbering concept
- Receipt footer note

Settings changes should remain Owner/Admin only and audited. v0.15.0 does not add heavy multi-branch architecture beyond existing branch support.
