# Premium Clean UI Guide

Normal receptionist, doctor, and patient workflows should stay clean and operational.

- Avoid visible demo/test/training/local-dev wording in normal workflow UI.
- Keep buttons and cards light, professional, and tactile with subtle depth.
- Avoid large explanatory blocks on workflow pages.
- Keep language switching and account/logout visible on small screens.
- Use compact stat cards and wrap chips/buttons instead of allowing horizontal overflow.

Safety and deployment limitations belong in docs and Owner/Admin readiness areas, not daily reception or doctor workflows.
