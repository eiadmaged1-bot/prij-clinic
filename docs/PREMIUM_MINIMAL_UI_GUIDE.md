# Premium Minimal UI Guide

Normal screens should feel like a real clinic workspace: calm, compact, and direct.

Rules:
- Use short headings and short supporting copy.
- Do not show demo/local/not-real/not-production wording in normal workflow UI.
- Use compact KPI cards with a short label, large value, and optional tiny context.
- Avoid bulky module showcases, oversized empty cards, decorative overlays, and long explanatory banners.
- Use soft shadows, subtle borders, 8px radius, clear spacing, and consistent button sizes.
- Preserve mobile, tablet, laptop, and desktop layouts without horizontal overflow.
