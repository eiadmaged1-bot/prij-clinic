# Calendar Queue Doctor Handoff

Calendar and queue pages now present focused daily operations rather than broad placeholders.

Visible handoff:
- Scheduled appointment.
- Check-in or walk-in.
- Waiting queue.
- Doctor waiting list.
- Start or resume visit from the patient workspace.
- Completed queue/visit status.
- Operational invoice/payment note when available.

Audit remains server-side through existing appointment, queue, encounter, invoice, and payment events. Billing status is an operational note, not a clinical blocker.
