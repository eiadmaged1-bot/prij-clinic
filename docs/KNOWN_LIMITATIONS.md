# Known Limitations

- Medication pregnancy/lactation profiles are seeded as review-required placeholders.
- No real pregnancy/lactation safety claims are included.
- Lactation profile is not a universal letter category.
- Legacy A/B/C/D/X categories are reference metadata only.
- Category `E` is invalid and maps to `REVIEW_REQUIRED` on import.
- Care Assist findings depend on currently available structured fields.
- Browser interaction testing for the new UI still needs a running dev server.
