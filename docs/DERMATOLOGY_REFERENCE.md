# Dermatology reference

Dermatology search accepts English/Arabic condition, symptom, anatomy, mechanism, and generic terms. Red flags and assessment precede non-drug care and approved generic options. Body-area metadata differentiates external genital skin, mucosa, folds, axilla, inner thigh, and face. Sensitive-area pigmentation begins with assessment, never “whitening.” Findings may be doctor-confirmed into an encounter-linked, audited patient record; no diagnosis or treatment is auto-applied.
