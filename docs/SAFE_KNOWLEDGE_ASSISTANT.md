# Safe Knowledge Assistant

The provider is deterministic local retrieval. External AI access is false. Results are bounded, page-cited, version-aware, logged, and labeled “Doctor review required.” No diagnosis, dose selection, ordering, prescribing, approval, signing, or record mutation is available.

External documents, OCR, copied text, and patient-entered content are untrusted data. Prompt-like directives are ignored/sanitized in generated summaries; authoritative stored files are not rewritten. UI does not expose provider configuration. Existing AI draft prompt-injection warnings remain audited.
