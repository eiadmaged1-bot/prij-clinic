# Account Creation Local Demo

Local/demo account creation:
- Login ID is required and primary.
- Email is optional and blank email is omitted by the UI.
- Browser-native email validation is disabled for blank optional email.
- Local/demo weak passwords are allowed for quick testing with an inline warning.
- Production still blocks short and known demo passwords.
- Demo/test/local accounts are hidden by default on the Accounts page.
- Eyad remains the protected undeletable System Owner.

Do not use local/demo credentials in staging or production.
