# Clinical Note Hint Engine

v0.12.4 adds doctor-facing clinical note buttons:

- Show clinical considerations
- Show medication options for review
- Show dosing note from saved template
- Insert selected note into draft
- Dismiss note

All notes are labeled Doctor review required. Notes remain in the side panel until the doctor explicitly inserts them into the draft. Inserted notes go to draft fields only and must still be saved and reviewed by the doctor.

No new runtime OpenAI clinical call is added in this sprint.
