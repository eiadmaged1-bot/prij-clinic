# v1.2.0 Mouse-First Case Feed Productivity

v1.2.0 adds the mouse-first doctor workflow, patient case feed, smart tags, Mother-Baby workspace, results review inbox, favorites, auto-save, continue-last-work, clinic day checklists, waiting alerts, print helpers, guided staff help, and copyable message templates.

Routine documentation should be 95-99% mouse/touch driven. Free text remains a fallback for unusual details.

Safety boundaries:
- No automatic diagnosis, prescribing, dosing, or treatment ranking.
- Doctor approval remains required before clinical records are saved.
- Patient case feed is internal only, not Facebook or social posting.
- Tags are role-aware and searchable.
- Mother, Baby A, and Baby B data are separated.
- Conception method tags include طبيعي / تنشيط تبويض / حقن مجهري ICSI / غير معروف.
- Real patient data remains blocked until signoff.
- External AI remains disabled by default.
