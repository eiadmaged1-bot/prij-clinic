# Responsive Layout QA

v1.2.1 responsive coverage targets:
- Mobile portrait and landscape
- Tablet portrait and landscape
- Laptop 1366x768
- Desktop 1920x1080
- Browser zoom 90%, 100%, 125%
- English LTR and Arabic RTL

Critical screens include login, reception home, waiting line, returning patient search, QR/manual fallback, new patient, patient file, doctor waiting, doctor queue preview, doctor visit cockpit, case feed, Mother-Baby, pregnancy, gynecology, prescription, investigations, billing, reports, guideline library, AI assistant, and admin/security pages.

Required guards: no horizontal overflow, visible language/account/logout, readable mobile tables/cards, wrapped clinical chips, bounded note previews, and usable QR/manual input.
