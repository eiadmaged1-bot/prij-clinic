# Doctor Queue Preview

Doctors can open any waiting patient from the doctor waiting list before starting the visit.

Preview actions:
- Open profile
- Preview history

These actions do not change queue status and do not mark the patient with the doctor. Only `Start Visit` selects the patient for the doctor.

Preview mode displays: `Preview mode — visit not started` and `وضع المعاينة — الزيارة لم تبدأ`.
