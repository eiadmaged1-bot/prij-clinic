# Today's Desk Workflow

v1.3.3 redesigns Today's Desk as a compact board for front-desk and doctor handoff work.

## Layout

- Header: Today's Desk, Next patient, Waiting, With doctor, Completed.
- Metrics: Next, Waiting, With doctor, Completed.
- Tabs: Waiting, With doctor, Completed, Appointments, Pending results.
- Rows: time, patient name, visit type, status, Open.

Cards are only used for rows and expanded context. The default view avoids repeated appointment cards, long text blocks, and duplicated schedule panels.

The board uses queue status consistently and keeps logout/account access visible through the global shell.
